**The Official scRNAseq Data Browser for Fliegauf et al. Nature Immunology 2026.**

The browser currently contains data from Fig. 2, Fig. 5 and Fig. 6 of the publication.

Fig. 2: Cortical tissue, leptomeninges and dura mater from control animals or 5d after BLZ945 or 8w after BLZ945. 
        Several metadata options can be chosen, including time point and cell subtype.
        Cell types included: stromal (Fibroblast, Endothelial, etc.), immune (macrophages, monocytes, etc.), glial (astrocytes, Schwann cells, etc.)
        
Fig. 5: - sdCAMs only data contains subdural CAMs without any choroid plexus CAMs
        - Microglia only data contains microglia from whole mouse brain
        - Full dataset contains all sorted immune cell types, mostly sdCAMs, Microglia and Monocytes

Fig. 6: scATACseq data of dural and subdural CNS macrophages, microglia and blood monocytes 8w after BLZ945 or CTL 
        - the data is currently limited to the gene activity matrix, an inferred RNA expression based on the accessibility of genetic regions
        - this data was used to create the RNA-ATAC based signatures of the atlas
        - actual called peaks data is too large to include directly in this app
        - a future update is planned to provide browsable peaks data

Check the browsable atlas here: https://019ff526-d41d-8795-3dcf-19f5317bab28.share.connect.posit.cloud/
